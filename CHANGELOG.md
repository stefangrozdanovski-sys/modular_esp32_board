# Changelog

## v2.0 (unreleased, untested)

- First public release of the ESP32 Modular Base v2.0 hardware: KiCad 7 project, generator scripts, Gerbers, schematic PDF, assembly guide, iBOM, BOM workbook and BOM app.
- 5 PCBs ordered from Seeed Fusion on 2026-10-14. Not yet assembled or tested.
- Added `production/pcba/`: JLCPCB and PCBWay BOM and CPL for the 54 SMD parts, generated by `hardware/tools/pcba.py` from `parts.py` and the KiCad position file. The fab BOM uses ESP32-WROOM-32E-N4. LCSC numbers (except CH340C) and JLCPCB rotation corrections are not verified yet.
- `export.sh`: the position export used `--exclude-dnp`, which KiCad 7 lacks, so it failed silently. It now uses `--smd-only` and runs `pcba.py`.
- Planned next: ESPHome firmware packages (`firmware/`), real photos and a test report.
