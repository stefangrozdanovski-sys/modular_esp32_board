# Changelog

## v2.0 (unreleased, untested)

- First public release of the ESP32 Modular Base v2.0 hardware: KiCad 7 project, generator scripts, Gerbers, schematic PDF, assembly guide, iBOM, BOM workbook and BOM app.
- 5 PCBs ordered from Seeed Fusion on 2026-10-14, received 2026-11-05. Not yet assembled or tested.
- BOM app: country-specific import VAT note replaced with a generic one.
- ESPHome firmware (`firmware/`): `base.yaml` (board setup and port pins as substitutions), 12 port-job packages (relay, dry_contact, ds18b20, ntc, analog, pulse_flow, pzem, rs485_modbus, i2c, i2c_bme280, out_pwm, out_switch) and 3 examples (test-board, energy-relay, greenhouse). Checked with `esphome config` on ESPHome 2026.10.2, not yet run on hardware. The `pulse_flow` factor (pulses per litre) is a placeholder until the flow sensor is chosen.
- Added `production/pcba/`: JLCPCB and PCBWay BOM and CPL for the 54 SMD parts, generated by `hardware/tools/pcba.py` from `parts.py` and the KiCad position file. The fab BOM uses ESP32-WROOM-32E-N4. All 24 LCSC numbers checked on JLCPCB on 2026-11-05. JLCPCB rotation corrections are not confirmed yet.
- `export.sh`: the position export used `--exclude-dnp`, which KiCad 7 lacks, so it failed silently. It now uses `--smd-only` and runs `pcba.py`.
- Planned next: confirm PCBA rotations in JLCPCB's preview, build and test the boards, real photos and a test report.
